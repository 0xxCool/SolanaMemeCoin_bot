### ⚠️ Known Issues

#### Issue 1: Cryptography Import Error
**Problem:**
```
ModuleNotFoundError: No module named '_cffi_backend'
pyo3_runtime.PanicException: Python API call failed
```

**Cause:**
- System cryptography (41.0.7) conflicts with user packages
- Missing PBKDF2 in system version

**Fix:**
```bash
pip3 install --user cffi
pip3 install --user --upgrade --force-reinstall cryptography
# OR use virtual environment (recommended)
```

**Status:** ⚠️ Workaround available, affects security module

#### Issue 2: Version Mismatches
- numpy 2.3.5 (required 1.26.4) - Major version bump
- May cause API compatibility issues

**Status:** ⚠️ Monitoring required, no issues found yet
